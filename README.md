# Çay Demlenmeden Hiçbir Şey Olmaz

## Bu Repo Nedir?

Bu, insanlık tarihinin en önemli bilimsel başarısıdır. Bir program, çay demlenene kadar bekler. Ama çay asla demlenmez. Çünkü suyun sıcaklığı asla 87.3 derece olmaz. 87.3 derece olmadan çay demlenmez. Demlenirse de tadı olmaz. Tadı olmazsa içilmez. İçilmezse hiçbir iş yapılmaz.

Bu kod, çayın demlenmesini simüle eder. Sonsuza kadar. Gerçekten çalışır. Durdurmak için Ctrl+C yapmanız gerekir, ama yapmayın, çünkü çay demleniyor olabilir.

## Nasıl Çalıştırılır?

```bash
python cay_bekleyen.py
```

Ve bekleyin. Sonsuza kadar.

## Özellikler

- Sonsuz döngü
- Rastgele sıcaklık kontrolü
- Asla bitmeyen bekleyiş
- Türkçe şikayetler
- Kahve karşıtı (kahve içenler bu repoyu kullanamaz)

## Lisans

Bu proje, çay içmeyenlere karşı lisanslanmıştır. Kullanmak için en az bir bardak çay içmiş olmanız gerekir.
